## 🚀 Featured Projects

### 🕷️ Speech & Web Controlled Surveillance Spider Robot
*Raspberry Pi & Arduino · Personal/Academic Project, 2026*

- 8-legged surveillance robot with dual control modes: **voice commands** and a **real-time web interface**
- Raspberry Pi handles speech recognition and HD video streaming; Arduino UNO coordinates **8× MG996R servo motors** via an L298N driver, giving **3-DOF-per-leg** walking gaits
- Obstacle avoidance using an **HC-SR04 ultrasonic sensor** for autonomous course correction
- Browser-based control panel with live Pi Camera streaming for directional control and monitoring

### 🔐 Smart Lock: IoT-Based Multi-Authentication Access Control
*Arduino Uno · Personal/Academic Project*

- Multi-modal smart door lock using **RFID (MFRC522)**, **Bluetooth (HC-05)** and a **433 MHz RF remote**
- Relay-controlled solenoid with a **fail-safe default-locked state**; **>95% authentication success rate** in testing
- Embedded C++ firmware for RFID validation, Bluetooth command parsing and RF decoding, with status feedback on a **MAX7219 LED matrix**
- Circuit validated in **Tinkercad** before hardware assembly; total component cost under **$50**
